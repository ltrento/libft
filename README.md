# libft

A custom C library that reimplements a subset of the standard C library functions from scratch, plus additional utility functions. Built as a foundational project during the 42 curriculum (42 Firenze) to develop low-level programming and memory management skills.

## What it does
Reimplements libc functions (string handling, memory operations, type checking, conversions) without using the standard library equivalents, plus a linked-list utility set and additional helper functions like `ft_split`, `ft_itoa`, and `ft_strtrim`.

## Skills demonstrated
- Manual memory management (malloc/free, no leaks)
- Pointer arithmetic and string manipulation in C
- Understanding of how standard library functions work internally
- Linked list implementation and manipulation

## Build
\`\`\`bash
make
\`\`\`
This compiles the library into `libft.a`, a static library you link against in other C projects.
